# Editor guide (quick start)

**Sign in:** <https://www.mercyseatchapel.org/admin/>, or <https://mercyseatchapel.sanity.studio>

The **Dashboard** tab shows quick actions, drafts, upcoming events and recent changes. The **Content** tab lists everything you can edit.

## The basics

1. Open an item, or press a quick action to create one.
2. Type in the fields. Each field explains what it's for. Changes save automatically as a **draft**.
3. Open the **Preview** tab to see how it will look.
4. Press **Publish**. The website updates within a few minutes.

If you don't see Publish, a publisher will review your draft.

## Common tasks

| I want to… | Go to |
|---|---|
| Change today's livestream video | Site Settings → **Watch Live** → paste the YouTube link → Publish |
| Add a special event (conference, fast, program) | Events & Programs → Special events → **+**. Add the dates, times, flyer and buttons. It shows in the slider until its end date. |
| Cancel one week's Bible Study | Events & Programs → Regular gatherings → Bible Study → *When & where* → **Exceptions → Add** → date + "Cancelled" |
| Post an announcement in the slider | Announcements → **+**. Add an image and tick "Show in What's happening". |
| Add a sermon to “More messages” | Sermons → **+**. Paste the YouTube link; the thumbnail is automatic. |
| Change a hero slide | Homepage → Hero slides. Drag to reorder, or untick "Show this slide" to hide one. |
| Update the phone number, address or service times | Site Settings (if it's locked, ask an administrator) |
| Open or close a job | Job Center → the job → Status |

## Good habits

- **Describe every picture** in its alt text field: what someone would need to know if they couldn't see it.
- Use wide photos for the hero and posters for events. Use the **focus point** (the circle on the image) to keep faces in view.
- To reuse a picture, click **Select** on an image field to browse earlier uploads.
- Never add private details (home addresses, personal phone numbers, prayer requests) to public content.
